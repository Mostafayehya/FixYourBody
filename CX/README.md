# Knee Rehabilitation Programs — image-inclusive Markdown files

Included:

- `Original_3_Day_Rehabilitation.md` — reproduces the original program, including its dosage and weekly schedule, with local exercise illustrations.
- `Revised_3_Day_Rehabilitation.md` — revised lower-limb-focused three-day program, with images, dosing, cues, and progress tracking.
- `images/` — **local** PNGs shared by the programs in `CX/`, `DP/`, and `GM/`. Keep these folders together and preserve their layout when moving or sharing the programs.

Open the `.md` files with VS Code Markdown Preview, Obsidian, Typora, or any Markdown renderer. Exercise images use consistent thumbnail sizes in the tables. Extract any ZIP first and keep the folder layout intact so all relative images load.

## Important

The exercise illustrations were AI-generated and may contain simplified or inaccurate details. They are visual aids, **not medical instructions**. Follow clinician-guided technique and stop or modify exercises if symptoms worsen.
